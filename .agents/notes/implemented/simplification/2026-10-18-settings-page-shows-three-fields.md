# Agent Note: 设置页只留三个问题，其余字段不进界面

Status: implemented

## Problem

设置页曾经是 12 个字段平铺，2026-09-24 折成两层：常显三项，其余九项收进「高级设置」。折叠解决了"一屏 11 个控件"，但没解决"这一页在问用户它不该问的问题"。

2026-10-18 用户的原话是："你这里搞的浏览器设置是干啥的，我作为用户不懂啊，有必要暴露这么多东西给我设置吗"。两处具体证据：

- 折叠上写着「2 项已自定义」，而点亮它的正是 `viewportWidth: 1000` / `viewportHeight: 1240` —— 两个连维护者都要解释半天、且面板连上后就被覆盖的字段。计数在替一页不该存在的控件作证。
- 窗口模式的选项写作"无头（无窗口）"与"带窗口"，用户读出了**三种**东西（侧栏、窗口、后台）。术语本身就在制造误解：侧栏在两种模式下都在，真正的选择只有一个。

## Decision

设置页只渲染三行：窗口模式、浏览器、Profile（选了长期才出现目录输入框）。这三项无法从使用方式推断，答错会直接导致"浏览器起不来"或"登录态丢了"。

其余九个 volatile 字段**整块不在页面上**，只在 `cordis.yml` / 组合配置里设置：`stealth`、`executablePath`、`debugPortMin`、`debugPortMax`、`viewportWidth`、`viewportHeight`、`quality`、`snapshotAttributes`、`snapshotIgnore`。每条为什么留在页外，写在 `HIDDEN_FIELDS` 的文档注释里（`src/client/settings-layout.ts`），一句话一条：默认值就是唯一的合理值、只有失败才会来改、或者面板一连接就覆盖。

三件事一起保住：

- **字段表仍是单一来源。** `FIELD_PLACEMENTS`（三项）+ `HIDDEN_FIELDS`（九项），`test/settings-layout.test.ts` 要求两者之和恰好等于 schema 里 volatile 的集合、且互不相交。新增一个 volatile 字段而不登记，测试直接红 —— 隐藏不是"忘了"，是被写下来的决定。
- **控件穷尽性不变。** `settings.tsx` 的 switch 仍以 `unreachableField(field: never)` 兜底，漏写控件 `tsc` 失败。隐藏的字段仍有控件代码：将来要放出来，一行 placement 就够。
- **文案仍是 total 的。** `FIELD_COPY` 覆盖全部字段（含隐藏的），所以隐藏字段的标签与说明留在两种语言里，重新暴露一个字段不需要新写 copy；`test/settings-layout.test.ts` 继续检查它们存在于 `en` / `zh`。

窗口模式的措辞一并改成描述"看得见的东西"而不是"实现方式"：

- 选项：`不显示窗口（只在侧栏看）` / `显示窗口（桌面也开一个）`；
- 说明：`侧栏两种模式都能看、都能操作，区别只在于桌面上有没有那个浏览器窗口。`

## Alternatives considered

**保留折叠。** 折叠挡住了控件，却挡不住"这一页有 12 个东西"的第一印象；用户仍然要判断自己该不该展开它，而正确回答永远是"不该"。折叠上那句"n 项已自定义"还会把最没意义的字段（视口宽高）推到最显眼的位置。

**从 schema 里删掉这九个字段。** 配置文件里也就没有了 —— 端口冲突、非标准安装路径、agent 快照调优这些真实故障从此没有修法。隐藏的意思是"不问你"，不是"不许改"。

**加一个"开发者模式"开关再显示它们。** 多了一层状态：谁记得自己开过、开关藏在哪；而出问题时最需要这些控件的人恰好不会想到先去打开它。多一层开关只把"12 个控件"变成"12 个控件 + 一个开关"。

**只改文案，控件不动。** 控件还在，问题只是变得更能读懂；而"这一页有 12 个东西"本身就是问题。文案改完之后，窗口模式那两项仍然需要用户先理解无头/有头才能做选择。

## Consequences

- 端口冲突、非标准安装路径、视口、画质、快照输出，现在都只能改配置文件。这九个字段仍是 volatile，所以改组合配置仍会重启在跑的浏览器 —— 只是没有页面上的入口了。
- 页面上的"重置"按钮只剩三项各自的覆盖清除。折叠消失之后，"被藏起来的改动"这个概念也不存在了，不再需要计数。
- 状态横幅里的会话明细仍收在 `<details>` 里（常显"有几个在跑"），这一处与本次改动无关。
- 本次只改客户端半边（`lib/client.js`），`dsh-client-hmr` 会把它推进在跑的 GUI，不需要重启 host；配置 schema 一行没动。
- 验证：`pnpm run typecheck`、`pnpm test`（490 个全绿）、`pnpm run build`；`lib/client.js` 里已无「高级设置」与三块分组文案，新选项文案在。
